# UX Backlog

These observations are intentionally deferred. Functional Completion did not redesign the established review-first, side-by-side document/evidence layout.

## Review and evidence

- Redesign Review as a unified but trust-layer-preserving workspace with richer queue grouping and progress visualization.
- Add page jump and evidence highlighting for PDF previews.
- Add a human-readable extraction text diff with page-level change navigation.
- Add review keyboard acceleration for accept, reject, edit and skip.
- Surface metadata and knowledge decision history in the browser.
- Explain stale-proposal conflicts with a focused “reload proposal” action.
- Show archived and OCR rendition provenance in document detail.

## Overview and navigation

- Design the final dashboard and its information hierarchy.
- Add restrained document, queue and review-backlog counts to Overview.
- Add an operational-status/settings view when that feature is scheduled.
- Revisit the disabled “Soon” navigation items once routes exist.

## Upload and processing

- Make drag/drop affordance and active drop state more explicit.
- Show stage-level ingestion progress and a compact completion summary.
- Add optional technical duplicate details such as content hash behind a disclosure.
- Add a supported fixture/document cleanup workflow for administrators.

## Lists and retrieval

- Redesign the Documents grid with a precision column system, density controls, and responsive priorities.
- Unify Documents list filtering and full-text retrieval entry points while preserving the difference in result behavior.
- Visually redesign Timeline and Upcoming once representative confirmed pilot data exists.
- Refine empty states across all lists after the primary workflows stabilize.
- Add visible page controls and totals to organization, contract and timeline lists when data volume requires them.
- Preserve advanced search-filter state across result/detail navigation.
- Add richer result-keyboard focus styling and an on-screen shortcut hint for `/` on non-Mac platforms.

## Visual polish

- Consolidate design tokens for color, spacing, radius and elevation.
- Refine typography and responsive spacing without changing information hierarchy.
- Standardize long-title clamping, expansion, and accessible full-title treatment across routes.
- Add restrained route and loading transitions.
- Add richer skeletons for knowledge and detail routes.
- Evaluate dark mode, mobile/PWA behavior and small-screen preview ergonomics.

## Future features, not UX fixes

- Atlas integration or chat/“Ask PDI”.
- Notifications and reminders.
- Automatic entity merging.
- Mobile/PWA offline behavior.
