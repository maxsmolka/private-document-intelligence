# PDI v1.3.0-rc.6

This immutable candidate is the clean executor-lease self-hosting target for M3.
It is intentionally functionally identical to RC5 apart from this release record.

The RC5 Update Manager must install RC6 without API startup misclassifying the live
host executor as abandoned. The disposable qualification must show a completed
history with no `crash_recovered` event, followed by a complete stack restart.

Prerelease discovery remains disabled by default. No production NAS or Paperless
service is involved.
