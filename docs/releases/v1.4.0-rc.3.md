# PDI v1.4.0-rc.3

This immutable release candidate corrects the pre-migration compatibility defect found by the official v1.3.0→RC2 disposable qualification. It is for disposable update testing only and must not be deployed to the production NAS.

RC2 made no deployment changes: its mandatory dry run stopped before Compose execution because the target-version helper tried to read the v1.4 `operational_settings` table from the source v1.3 schema. RC3 keeps the constrained executor on deployment-provided settings until the target migrations have completed, so both dry-run validation and execution remain compatible with the declared minimum schema `20260828_0015`.

A regression test makes any pre-migration read of target-only operational settings fail explicitly. The complete qualification must begin again from clean official v1.3.0 images and schema `20260828_0015`, create a fresh verified backup, complete the mandatory dry run, execute the five-service immutable target deployment, rebuild search before readiness, preserve the synthetic archive and authentication state, finish at schema `20260828_0020`, and retain a completed 12-stage journal after full-stack restart.
