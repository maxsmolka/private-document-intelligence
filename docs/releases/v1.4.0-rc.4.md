# PDI v1.4.0-rc.4

This immutable release candidate makes the controlled-update audit journal deterministic after the otherwise successful official v1.3.0→RC3 disposable qualification. It is for disposable update testing only and must not be deployed to the production NAS.

RC3 completed the five-service immutable update, migrated schema `20260828_0015` to `20260828_0020`, rebuilt and verified search, preserved both synthetic documents and authentication state, retained a verified rollback backup, passed readiness and storage reconciliation, and survived a full six-service Compose restart. All twelve expected events were present and the API returned them in lifecycle order.

Direct database inspection found that `images_verified` and `deployment_pinned` shared one PostgreSQL transaction timestamp. Their relative order therefore depended on unspecified tie ordering after operations such as backup and restore. RC4 commits the image-verification event before pinning the deployment and adds an exact journal-sequence regression test. Full qualification must repeat from clean official v1.3.0 images and retain the exact completed twelve-stage journal after full-stack restart.
