# PDI v1.3.0-rc.4

This immutable candidate is the final M3 self-hosting target. It is intentionally
functionally identical to RC3 apart from this release record, so a corrected RC3
Update Manager can prove the complete discovery, backup, mutation, verification,
restart, and durable-history path against a distinct official release.

Prerelease discovery remains disabled by default and is enabled only in the
disposable UAT environment. No production NAS or Paperless service is involved.
