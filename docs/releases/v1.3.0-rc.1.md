# PDI v1.3.0-rc.1

Release candidate for disposable validation of the Controlled Update Manager. It is not approved for production NAS deployment.

- Adds strict official release discovery and machine-verifiable manifests.
- Adds deterministic planning, preflight, run-specific verified backup, maintenance/drain, and durable history.
- Adds the constrained host-side Compose executor and stage-aware rollback semantics.
- Migrates the database to `20260827_0014`.

Prerelease discovery remains disabled by default and must only be enabled in the disposable UAT environment.
