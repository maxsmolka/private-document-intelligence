# PDI v1.3.0-rc.2

Second release candidate for the disposable self-hosting qualification of the Controlled Update Manager. It is not approved for production NAS deployment.

- Produces a fresh official immutable target for the RC1-managed update E2E.
- Adds an isolated host-executor test image that combines the official PDI CLI with a pinned Docker Compose client without exposing Docker to the API.
- Adds a disposable Compose override for exact-digest v1.2.0 bootstrap and subsequent prerelease-manager validation.
- Retains schema `20260827_0014`; migration execution remains idempotent for direct v1.2.0 compatibility.

Prerelease discovery remains disabled by default and must only be enabled in the disposable UAT environment.
