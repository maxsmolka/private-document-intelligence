# PDI v1.0.0

PDI v1.0.0 is the first stable release of a private, self-hosted document intelligence system. It combines safe ingestion and OCR with reviewable metadata, search, a grounded document knowledge model, and operational tooling for replacing Paperless without surrendering source provenance.

This is the first public release, so there is no supported upgrade path from an earlier public version. Existing private-development installations must create and verify a full backup before adopting these images.

## Highlights

- Immutable originals and content-addressed OCR renditions with versioned extraction provenance.
- Review-first intelligence for metadata, organizations, contracts, relationships, dates, deadlines, and actions.
- Fast German full-text search with page-grounded snippets and identifier-aware ranking.
- Responsive authenticated web experience for documents, search, review, knowledge, timeline, and upcoming work.
- Resumable Paperless migration, verified backup/restore, open export, health, and readiness workflows.
- Non-root backend and web images published with OCI metadata, SBOM, and provenance attestations.

## Deployment notes

Use `compose.release.yaml` with a protected `.env.release` created from `.env.release.example`. Terminate TLS at a trusted private reverse proxy and keep PostgreSQL and the API off public host ports. Create the first local user with `docker compose --env-file .env.release -f compose.release.yaml run --rm api pdi user create admin`.

- `ghcr.io/maxsmolka/private-document-intelligence/backend:1.0.0`
- `ghcr.io/maxsmolka/private-document-intelligence/web:1.0.0`

Back up PostgreSQL and document storage together before every upgrade. This release is qualified for `linux/amd64`.

Treat API tokens, backup archives, exports, and document storage as secrets. Review `SECURITY.md` and `docs/SECURITY.md` before exposing PDI beyond a trusted environment.

## Known limitations

- Intended for a trusted private network or VPN, not direct Internet exposure.
- No MFA, SSO, per-document RBAC, antivirus scanning, or application-layer encryption.
- OCR and document parsers remain native-code risk boundaries despite bounded execution.
- Semantic retrieval and external AI providers are disabled by default; deterministic local intelligence is the baseline.
