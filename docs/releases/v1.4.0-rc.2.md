# PDI v1.4.0-rc.2

This immutable release candidate corrects the two deployment-procedure defects found by the official v1.3.0→RC1 disposable qualification. It is for disposable update testing only and must not be deployed to the production NAS.

RC1 safely reached schema `20260828_0020` but entered `rollback_required`: migration 0019 intentionally made the existing search projection stale, while the executor attempted full readiness before the manifest-required rebuild. RC2 rebuilds first and then requires readiness plus independent search verification.

The RC2 qualification also uses the exact target-version constrained helper and target Compose definitions. This expands the immutable managed overlay from the v1.3 API/worker/web set to include the v1.4 backup and reminder schedulers. Both new services must be started at the target backend digest and included in restart/durability verification.

Qualification must begin again from clean official v1.3.0 images and schema `20260828_0015`, create a fresh verified backup, execute without replaying either failed RC1 run, preserve the synthetic archive and authentication state, finish at schema `20260828_0020`, and retain a completed 12-stage journal after full-stack restart.
