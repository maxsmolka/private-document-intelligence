# PDI v1.4.0-rc.1

This immutable release candidate qualifies the final PDI Roadmap Completion release before v1.4.0 publication. It is for disposable update testing only and must not be deployed to the production NAS.

The candidate contains the complete v1.4.0 feature set: hardened consume-folder and read-only IMAP ingestion, safe runtime administration, improved German document intelligence, structured PostgreSQL retrieval and facets, in-app deadline reminders, and resumable Paperless full-cutover preservation and verification.

## Qualification target

- Start from the official immutable PDI v1.3.0 images and schema `20260828_0015` in disposable infrastructure.
- Discover this prerelease only with the disposable prerelease switch enabled.
- Validate the release manifest, exact image digests, OCI version/revision labels, SBOM, and provenance.
- Require a fresh verified backup, drain execution safely, migrate through schema `20260828_0020`, rebuild search, and pass readiness, search, storage, execution-state, and durable update-history checks.
- Restart the complete stack and prove that the completed update is not replayed.

PDI v1.2.0 cannot invoke the Update Manager. Its one-time path remains the separately qualified backup-first manual bootstrap to v1.3.0. Production NAS and Paperless services are outside this RC test.
