# PDI v1.0.1

PDI v1.0.1 is a focused security patch for the authenticated web application.

## Security

- Post-login redirect destinations are now restricted to validated internal PDI paths. Invalid or external destinations safely return to the overview.

Authentication, session, CSRF, logout, document processing, storage, and database behavior are otherwise unchanged from v1.0.0.

## Deployment

Use `compose.release.yaml` with a protected `.env.release` created from `.env.release.example`. Back up and verify PostgreSQL and document storage together before upgrading. Production deployments must use the explicit `1.0.1` version or the recorded immutable image digests, not `latest`.

- `ghcr.io/maxsmolka/private-document-intelligence/backend:1.0.1`
- `ghcr.io/maxsmolka/private-document-intelligence/web:1.0.1`

This release is qualified for `linux/amd64` and includes SPDX SBOM and provenance attestations for both images.
